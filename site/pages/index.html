// a naming scheme

Three suffixes. Zero dragging.

Name spaces CUSTOMER - project, mark the ones you always want on top with + and the parking lot with -. Space Herder does the rest.

  • ~Home, always first.
  • LUMON +The head group, always on top.
  • ACME - apiOne colour per customer, side by side, worktrees right under their parent.
  • SYS -The bottom group, out of the way.

// small on purpose

Short scripts you can read before you run them.

Nothing else to install

Python standard library only, from 3.9 (the system Python of macOS, with the Command Line Tools) to the latest.

Read it first

Herdr shows the manifest and the commands before installing. The code is plain Python: no build step, no dependencies.

Tested on every push

CI runs every plugin's tests on macOS with the system Python and with Python 3.13 and 3.14, and on Ubuntu.

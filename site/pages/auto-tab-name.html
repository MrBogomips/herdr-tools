auto-tab-name

Tabs that name themselves. Every Herdr tab takes the name of the folder its pane is in, keeps it in sync as you and your agents move around, and leaves alone the tabs you name yourself.

herdr plugin install MrBogomips/herdr-tools/auto-tab-name
Formats Agents in worktrees Your names stay Key bindings Shell integration Configuration Good to know
// 01

Pick what a name shows

Herdr shows a tab nobody named as its position number. auto-tab-name renames those tabs after their pane's folder, and only writes when a name changes. For ~/tools/initech/sort, inside the repository initech on branch main:

formatNameOutside a repository
basename (default)sortsame
repoinitech/sortlike basename
last_ninitech/sort, the last depth folderssame
home_path~/tools/initech/sortsame
repo_branchinitech@main, or the short hash when detachedlike basename

A linked worktree shows the name of its main repository. The repository is found by reading .git: no git process runs.

// 02

It follows your agents into worktrees

By default the name comes from the folder of the program in the foreground, not the shell's. When an agent started in ~/tools/initech goes to work in the worktree .worktrees/login, its tab says so:

format"cwd" (the shell)"foreground_cwd" (default)
basenameinitechlogin
repo_branchinitech@maininitech@feature/login

Herdr has no event for a folder change, so the name follows at the agent's next change of state: when it gets ready, and at the latest when the turn that moved it ends.

// 03

Your names stay yours

  • A new tab shows its position number, so it follows its folder from the start.
  • Rename a tab by hand and it stops following: your name stays.
  • follow makes it follow again, and so does renaming it back to its position number.
  • A Herdr restart changes nothing: tabs already named like their folder count as followed.
// 04

Key bindings

Bind the actions you want in ~/.config/herdr/config.toml, then run herdr server reload-config:

[[keys.command]]
key = "prefix+alt+c"
type = "plugin_action"
command = "mrbogomips.auto-tab-name.configure"

[[keys.command]]
key = "prefix+alt+t"
type = "plugin_action"
command = "mrbogomips.auto-tab-name.toggle"

[[keys.command]]
key = "prefix+alt+f"
type = "plugin_action"
command = "mrbogomips.auto-tab-name.follow"
ActionWhat it does
configureOpens the configuration popup
toggleTurns auto_sync on or off
syncNames every followed tab now
follow / unfollowMakes the current tab follow its folder, or keeps its name as it is
refreshThe quiet run, for the shell integration
// 05

Instant names with shell integration

Without it, a name catches up at the next focus or tab change. To rename as soon as you cd, add the lines for your shell; bash and fish versions are in the README.

# ~/.zshrc
if [[ $HERDR_ENV == 1 && -n $HERDR_BIN_PATH ]]; then
  autoload -Uz add-zsh-hook
  _auto_tab_name_chpwd() { "$HERDR_BIN_PATH" plugin action invoke mrbogomips.auto-tab-name.refresh >/dev/null 2>&1 &! }
  add-zsh-hook chpwd _auto_tab_name_chpwd
fi

It runs only inside Herdr, in the background, so the prompt never waits.

// 07

Good to know

  • No Herdr event fires on cd: without the shell integration a name catches up at the next focus or tab change.
  • A tab with several panes uses the pane you focused last in it.
  • With repo or repo_branch, a git repository in your home folder (dotfiles, say) names every folder under home that is in no other repository.
